## 第一批：智能记餐闭环 ✅ v3.0.0

流程：**描述这一餐 → 识别 → 匹配候选 → 用户校对 → 保存**

| 规则 | 实现 |
|---|---|
| AI 只识别与匹配，不产生营养值 | `MealParser` 只输出「食物 + 克数」，营养由字典资料 × 克数计算 |
| 匹配不到不伪造 | 未命中条目显示「未匹配」，不进入保存 |
| 模糊份量必须可改 | 一碗/两个等按「一份」换算后仍需用户确认，可 ±25 g 调整 |
| 未确认不落库 | 只有点了「保存 N 条」才写入 |
| 最近使用/复制上一餐等确定性能力保留 | 原有搜索与字典入口不变 |

确定性部分已有 6 个单测覆盖（切分、显式克数、模糊单位换算、未匹配、最长名称优先、空输入）。
