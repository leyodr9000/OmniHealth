## 3. 十分钟自验清单

1. **冷启动**：杀掉进程重开，首页 1 秒内出内容
2. **记录闭环**：记录 → 饮食里点食物 → 加 300 g → 首页热量变化
3. **编辑**：点该记录 → 改 350 g → 保存 → 热量按比例更新
4. **删除撤销**：点 ✕ → 底部出现「撤销」→ 点原生还
5. **补录**：日期切到昨天 → 加一条 → 切回今天，今天不受影响
6. **缺失值**：全新安装时首页显示 `— / 未记录`，健康分显示 `— / 数据不足`
7. **备份**：设置 → 备份数据 → 分享面板出现 → 把 JSON 发给自己
8. **恢复**：设置 → 恢复备份 → 选该文件 → 弹出记录数确认 → 确认后数据回来
9. **提醒**：打开饮水 → 看到 08:00–22:00 / 每 2 小时 → 改间隔 → 重启仍保持
10. **AI**：无 Key 时生成报告 → 标注「本地分析 / 覆盖 7 天 / 缺少…」

## 4. 已知限制（不打算在本轮修复）

| 限制 | 影响 | 原因 |
|---|---|---|
| 真机性能未采集 | 无法确认 8 Elite 上的帧率 | 需物理设备，协议已备好 |
| 键盘弹起未验证 | 输入框可能被遮挡 | 无头模拟器无法唤起 IME |
| TalkBack 未走查 | 可访问性未知 | 同上 |
| 时区回溯未启用 | 跨时区历史归属不变，但不做二次校正 | 已存 offset，属可选增强 |
| 无收藏/复制上一餐 | 录入效率略低 | 属功能扩张，非本期目标 |
| 恢复流程未端到端自动化 | 依赖手动点一次 | SAF 无法脚本化 |

## 5. 隐私说明

- 健康数据仅存本机 Room；`allowBackup=false`，不进系统云备份
- API Key 用 Android Keystore 加密；导出与备份均不含凭据
- 只有开启在线 AI 且用户确认后，才发送「7 天摘要」（无姓名、无原始记录）
- 自定义接口默认要求 HTTPS；公网明文地址直接拒绝并回退本地引擎

## 6. 如何继续

```bash
git clone https://github.com/leyodr9000/OmniHealth
cd OmniHealth
./gradlew :app:assembleRelease   # 需要 keystore.properties
./gradlew :app:testDebugUnitTest # 25 个测试
```

性能数据回来后按 [PERF_BASELINE.md](PERF_BASELINE.md) 的判定标准决定是否继续优化渲染或查询。
