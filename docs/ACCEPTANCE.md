# 验收清单（对照片段式评估）

图例：
- ✅ 已实现且**实测通过**（模拟器或单测，注明方式）
- 🟡 已实现，**未在真机验证**
- ⛔ 未实现 / 已知缺口

## 一、数据一致性

| 场景 | 状态 | 证据 |
|---|---|---|
| 添加饮食后首页/饮食页/图表一致 | ✅ | 138 kcal 同步出现在首页与饮食页 |
| 删除饮食后可撤销且聚合恢复 | ✅ | 删除 → 0 kcal；撤销 → 138 kcal、P 3 g |
| 编辑克数后按比例重算 | ✅ | 300 g → 350 g，138 → 161 kcal |
| 历史补录不污染今天 | ✅ | 18 日补录 249 kcal，今天仍 138 kcal |
| 手动记录与传感器步数不混算 | 🟡 | 模拟入口仅 Debug 构建可见，正式包不可达 |

## 二、日期与统计口径

| 场景 | 状态 | 说明 |
|---|---|---|

| 时区变化后历史归属 | ⛔ | 记录只存 `epochDay`，跨时区会按本地日重算；属已知限制 |
| 睡眠按入睡日还是起床日 | ⛔ | 当前按「记录日」存，未区分入睡/起床 |
| 周一/周日为周首 | ⛔ | 未提供周视图 |
